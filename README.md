# Cinema Booking Service

Серверная часть сервиса бронирования билетов в кино.

## Возможности

* Регистрация и аутентификация пользователей
* Авторизация по ролям: пользователь и администратор
* Управление фильмами и жанрами
* Управление расписанием сеансов
* Просмотр фильмов и сеансов
* Просмотр доступных мест
* Бронирование и отмена мест
* Просмотр своих бронирований
* Управление бронированиями для администраторов
* Отчётность по бронированиям, вместимости и выручке

## Основные сущности

* Users
* Movies
* Genres
* Halls
* Sessions
* Bookings

## Цель

Практика проектирования реляционной модели данных, сложной бизнес-логики бронирования, работы с транзакциями и построения сложных SQL-запросов.
